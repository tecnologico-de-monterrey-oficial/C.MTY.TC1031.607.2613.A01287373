1. Instrucciones para compilar y ejecutar
Este proyecto está hecho en C++ y está dividido en 2 partes.

Parte A: Para ejecutarla, abrir el archivo ParteAmain.cpp que está en la carpeta src, compilarlo y darle a Run. El programa mostrará las pruebas de las diferentes estructuras de datos.

Parte B: Para ejecutarla, abrir el archivo ParteBmain.cpp que también está en la carpeta src, compilarlo y darle a Run. Primero se debe seleccionar uno de los archivos de logs y después aparecerá un menú con las diferentes opciones del programa.

Para que funcione correctamente, los archivos log607-1.txt y log607-2.txt deben estar en la carpeta data y el programa debe ejecutarse desde la carpeta src.

2. Formato de fechas esperado
Para buscar registros por día, la fecha se debe escribir en el siguiente formato:
Mes Día Año
Por ejemplo: Sep 14 2024
El mes debe escribirse con sus primeras 3 letras en inglés, seguido del día y el año, separados por espacios.
