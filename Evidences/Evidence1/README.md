Descripción:

Lo que hace este programa es leer archivos que contienen logs y permite su ordenamiento por fecha y hora a través del uso de diferentes algoritmos de ordenamiento.

Los algoritmos utilizados son:
- Swap Sort
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Shell Sort

Después de que se ordenan los datos el programa te permite buscar logs dentro de un rango de fecha y hora usando una busqueda binaria.

Los logs ordenados se guardan en output607.txt y los resultaods de la busqueda por rango se guardan en range607.txt

Para compilar el programa desde la terminal:

g++ -std=c++20 Evidencia1.cpp -o Evidencia1

Después, para ejecutarlo:

./Evidencia1

Formatos de fecha y hora

Para hacer la busqueda se deben ingresar solo las primeras 3 letras del mes. 

Ejemplos válidos:
sep
Sep
SEP

La hora debe escribirse así:
HH:MM:SS

Ejemplo:
14:30:25

De esta manera el programa válida que la fecha y hora sean reales, no aceptando fechas como Sep 40 ni horas como 25:70:00
